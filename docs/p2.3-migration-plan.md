> 状态：已完成<br>

> 日期：2026-11-17<br>
> 架构规范：[`archmap-architecture-spec.md`](archmap-architecture-spec.md)

## 1. 迁移目标

1. 将“物理代码单元”和“逻辑 Provider Role”分离；
2. 将 ArchMap 自身代码迁移到 `config / model / utility / managers / entry` 目录；
3. config/model 不再把序列化方法暴露为模块 API；
4. utility 默认 internal，不进入默认项目页/模块页；
5. 保留旧 import 路径作为兼容 shim；
6. 保持 CLI、bundle schema、HTML 行为稳定。

## 7. 最终清理（已完成）

P2.3 的过渡期兼容层已彻底移除：

- 删除根目录 12 个旧 import shim：analysis / callresolver / callsites / cli / config / contracts / details / discover / graph / pipeline / render / validate；
- 删除 4 个前端兼容 shim：`frontends/base.py`、`frontends/registry.py`、`frontends/python/capabilities.py`、`frontends/python/roles.py`；
- `archmap/frontends/__init__.py` 不再导出旧的 `FRONTENDS` / `get_frontend` 兼容入口；
- `pyproject.toml` 的 console script 改为 `archmap.entry.cli_entry:main`；
- 测试全部改为直接使用 `PipelineManager`、`ValidationManager`、`RenderManager`、`GraphManager` 与 canonical utility；
- 自举配置删除旧 shim 排除项；
- 新增迁移防回潮测试，禁止旧模块路径重新出现；
- bundle schema 保持 3.6，CLI 与 HTML 产物契约不变。
