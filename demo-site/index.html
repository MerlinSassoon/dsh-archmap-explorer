ArchMap

Static architecture maps for Python.
No install, no code execution.

Every demo below is a single self-contained HTML file produced by python3 -m archmap build .. Drill from the project overview to an execution flow, into a module's capability surface, down to a method's source and its callers — offline.

$ python3 -m archmap build .
$ dsh plugin add github:MerlinSassoon/dsh-archmap-explorer
